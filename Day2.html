DAY 2 - INTRODUCTION TO HTML

Building the Structure of Web Pages

1. WHAT IS HTML?

  • HTML stands for HyperText Markup Language.
  • It is used to structure and display the content on web pages.
  • It is a markup language.

2. HYPERTEXT AND MARKUP

HyperText

  • "Hyper" means a link.
  • Hypertext is clickable content that can take us to another page, image, video or resource.

Markup

  • "Markup" means tags are used to mark or structure the content.
  • HTML uses tags to tell the browser how to display the content.

3. HISTORY OF HTML

HTML was invented by Tim Berners-Lee in 1991 at CERN (Switzerland).

Year HTML Version Description
1991 HTML 1.0 First version (invented)
1995 HTML 2.0 Second version
1997 HTML 3.2 Third version
1999 HTML 4.01 Fourth version
2014 HTML 5.0 Latest major version (poster)

4. HTML TAGS

Paired Tags

  • Have an opening tag and a closing tag.
  • Example:

<h1> Welcome </h1>

Opening Tag: <h1>

Closing Tag: </h1>

Unpaired Tags

  • Some tags do not have a closing tag.
  • Example:

<br>

Line break tag

5. BASIC HTML STRUCTURE

<!DOCTYPE html>
<html>
    <head>
        <title>My First Page</title>
    </head>
    <body>
        <h1>Hi, Welcome to HTML!</h1>
    </body>
</html>

Explanation:

  • <!DOCTYPE html> - Declares the document type.
  • <html> - This is the root element.
  • <head> - Contains meta information (such as title).
  • <body> - Contains the visible content of the web page.

6. HTML ELEMENT

An HTML element consists of an opening tag + content + closing tag.

Example:

<h1> Hi, Welcome to HTML! </h1>

  • Opening Tag: <h1>
  • Content: Hi, Welcome to HTML!
  • Closing Tag: </h1>
  • The <h1> tag defines a heading.
  • This tag is used to display a main heading on the web page.
