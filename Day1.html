1. WHAT IS THE INTERNET?

The Internet is a global network connecting computers and devices worldwide to share information.

2. WHAT IS THE WEB?

The Web is a collection of websites and web pages accessed through the Internet.

3. WHAT IS A WEB BROWSER?

A Web Browser is software used to access and view web pages.

Examples:

  • Google Chrome
  • Microsoft Edge
  • Safari
  • Mozilla Firefox

4. WHAT IS A WEB PAGE?

A Web Page is a single page on the Web that can contain text, images, videos and links. It has a URL.

5. WHAT IS A WEBSITE?

A Website is a collection of related web pages under a domain name.

Examples of Website Pages:

  • Home
  • About
  • Contact

6. WHAT IS A WEB APPLICATION?

A Web Application is a website that lets users perform tasks, such as email, online shopping or document editing.

KEY TAKEAWAYS

  • Internet connects devices.
  • The Web provides pages and websites.
  • Browsers help us access web content.
  • Web applications let us interact and complete tasks.
